# Store release checklist

- [ ] Run `./gradlew testDebugUnitTest`
- [ ] Run `./gradlew lintRelease`
- [ ] Build and install a signed release APK/AAB
- [ ] Test clean installation and first-run selection
- [ ] Test upgrade from 1.0.3 without opening the app before/after update
- [ ] Verify add/remove behavior in Android Physical keyboard settings
- [ ] Test USB, Bluetooth, and dongle keyboards
- [ ] Test Turkish Q/F plus at least one RTL and one Cyrillic layout
- [ ] Test dark theme, large font, and RTL UI
- [ ] Update Play Store screenshots and release notes
- [ ] Verify privacy policy URL
- [ ] Confirm Data safety form declares no collected/shared data
